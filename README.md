If you have a Creality Ender 3 V3 and order the CoPrint module for it, you will get V3 Plus connection parts.
Print what you need from these files before you start to be able to assemble it properly.

These files should be in https://github.com/coprint/AssemblingParts/tree/main/Creality, but that repository only has files for the V3 Plus, V3 KE and V3 SE

These aren't my files.  They came from Creality on their supplied USB stick.  Some other people who have purchased this kit either didn't get the USB, or it didn't include the files, so I have made them available here.

When installing firmware, you can't use the supplied USB as it has an issue.  You need to download the latest firmware onto your own USB to do the upgrade.
